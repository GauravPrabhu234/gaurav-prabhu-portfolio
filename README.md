# Gaurav Prabhu — AI/ML Engineer Portfolio

## Stack
- React 18 + TypeScript
- Vite 6
- Three.js custom shader particle field
- GSAP + ScrollTrigger
- Tailwind CSS v4
- Lucide React icons

## Requirements
Node.js 20.19+ or 22.12+, plus npm.

## Run locally
1. Extract this ZIP.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL Vite prints.

## Production
- `npm run build`
- `npm run preview`
The deployable site is generated in `dist/`.

## Before publishing
- Replace project placeholders and sample technology tags with real details.
- Replace generic GitHub/LinkedIn links with your profiles.
- Verify skills and education wording.
- Check the resume URL and contact email.
- Google Fonts require an internet connection.

This is an independent rebuild based on the publicly visible portfolio and content available in the conversation, not an export of Framer's original project. Decorative visualizations are newly implemented. Compare with the live site in a browser before publishing.
